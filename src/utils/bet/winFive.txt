### **Understanding Winner Prediction in Bet9ja’s Virtual Sports**

**Bet9ja’s Approach**:
- **Virtual Football**: Each match (e.g., Lions vs. Eagles) has 1X2 odds (Team 1 win, Draw, Team 2 win). Outcomes are determined by an RNG with probabilities inversely proportional to the odds. For example:
  - Team 1: 2.0 odds → ~50% chance.
  - Draw: 3.5 odds → ~28.6% chance.
  - Team 2: 3.0 odds → ~33.3% chance.
  - The RNG selects the outcome when the match “ends” (~3 minutes).
- **Dog Racing**: Each dog (e.g., Dog 1 to Dog 8) has win odds (e.g., Dog 1: 2.0, Dog 8: 12.0). The RNG assigns higher probabilities to dogs with lower odds. For example:
  - Dog 1: 2.0 odds → ~50% chance.
  - Dog 8: 12.0 odds → ~8.3% chance.
- **RNG Fairness**: Bet9ja uses a certified RNG to ensure outcomes are random and unbiased, meeting regulatory standards (e.g., Nigerian Lottery Commission).

**Key Points**:
- **Weighted Probabilities**: Lower odds mean a higher probability of winning, but randomness ensures unpredictability.
- **Simulation**: Outcomes are generated at the end of each event (match or race), not pre-determined.
- **Transparency**: Results are displayed to users (e.g., “Lions 2-1 Eagles” or “Dog 1 wins”), with bets settled based on the outcome.

**Your App**:
- Your odds are generated randomly in `utils/oddsGenerator.js` with weighted probabilities (e.g., football favorites at 1.5–3.0, dogs at 2.0–10.0).
- To predict winners, you’ll convert odds to probabilities, use an RNG to select the outcome, and store/display the result.
- This must integrate with your existing features: real-time odds, Stripe payments, and in-game betting.

**Why Not Deterministic Prediction?**:
- Since outcomes are random, you can’t predict the exact winner in advance (e.g., “Lions will win”). Instead, you assign probabilities (e.g., Lions have a 50% chance) and let the RNG decide at the event’s end.
- This ensures fairness and mimics Bet9ja’s model, where no one (including the app) knows the outcome until the RNG runs.

###### **Update Odds Generator**

```javascript
const generateFootballOdds = () => {
  const favorite = (1.5 + Math.random() * 1.5).toFixed(2); // 1.5–3.0
  const draw = (3.0 + Math.random() * 1.5).toFixed(2); // 3.0–4.5
  const underdog = (2.5 + Math.random() * 2.5).toFixed(2); // 2.5–5.0
  return [
    { name: 'win1', odds: parseFloat(favorite) },
    { name: 'draw', odds: parseFloat(draw) },
    { name: 'win2', odds: parseFloat(underdog) },
  ];
};

const generateDogRaceOdds = () => {
  const dogs = [];
  for (let i = 1; i <= 8; i++) {
    const odds = (i === 1 ? 2.0 : i === 2 ? 3.0 : 4.0 + (i - 2) * 1.5).toFixed(2);
    dogs.push({ name: `Dog ${i}`, odds: parseFloat(odds) });
  }
  return dogs;
};

// Convert odds to probabilities and select winner
const selectWinner = (participants) => {
  // Convert odds to implied probabilities (1/odds)
  const totalInverseOdds = participants.reduce((sum, p) => sum + 1 / p.odds, 0);
  const probabilities = participants.map(p => (1 / p.odds) / totalInverseOdds);

  // RNG: Generate random number between 0 and 1
  const random = Math.random();
  let cumulative = 0;
  for (let i = 0; i < probabilities.length; i++) {
    cumulative += probabilities[i];
    if (random <= cumulative) {
      return participants[i].name;
    }
  }
  return participants[participants.length - 1].name; // Fallback
};

// Generate random football score based on winner
const generateFootballScore = (winner, team1, team2) => {
  if (winner === 'draw') {
    const score = Math.floor(Math.random() * 3); // 0-0, 1-1, 2-2
    return `${score}-${score}`;
  }
  const winningScore = Math.floor(Math.random() * 3) + 1; // 1–3
  const losingScore = Math.floor(Math.random() * winningScore); // 0–(winningScore-1)
  return winner === team1 ? `${winningScore}-${losingScore}` : `${losingScore}-${winningScore}`;
};

module.exports = { generateFootballOdds, generateDogRaceOdds, selectWinner, generateFootballScore };
```

const footballTeams = [

router.get('/', async (req, res) => {

    if (events.length === 0) {
      // Seed initial events: 10 football matches, 2 dog races
      const newEvents = [];
      for (let i = 0; i < 10; i++) {
        const team1 = footballTeams[i * 2];
        const team2 = footballTeams[i * 2 + 1];

        newEvents.push({

          ],
          date: new Date(Date.now() + i * 5 * 60 * 1000), // Every 5 minutes
          status: 'upcoming',

        newEvents.push({
          type: 'dog_race',
          sport: 'Virtual Dog Racing',
          participants: generateDogRaceOdds(),
          date: new Date(Date.now() + (i + 10) * 5 * 60 * 1000),
          status: 'upcoming',
        });
      }
      await Event.insertMany(newEvents);
      events = newEvents;
    } else {
      // Update status, odds, and results
      for (let event of events) {
        if (event.status === 'upcoming' && event.date < new Date()) {
          event.status = 'in-play';
        }
        if (event.status === 'in-play' && event.date < new Date(Date.now() - 3 * 60 * 1000)) {
          event.status = 'finished';
          event.result = selectWinner(event.participants);
          if (event.type === 'football') {
            event.score = generateFootballScore(event.result, event.participants[0].name, event.participants[1].name);

        if (event.status !== 'finished') {
          event.participants = event.type === 'football' ? generateFootballOdds() : generateDogRaceOdds();

```javascript
const express = require('express');
const auth = require('../middleware/auth');
const Bet = require('../models/Bet');
const User = require('../models/User');
const Event = require('../models/Event');
const router = express.Router();

// Place a bet
router.post('/', auth, async (req, res) => {
  const { eventId, amount, selection, type } = req.body;
  try {
    const user = await User.findById(req.user.userId);
    if (user.balance < amount) return res.status(400).json({ msg: 'Insufficient balance' });

    const event = await Event.findById(eventId);
    if (!event) return res.status(400).json({ msg: 'Event not found' });
    if (type === 'in-play' && event.status !== 'in-play') return res.status(400).json({ msg: 'Event not in-play' });
    if (!event.participants.some(p => p.name === selection)) return res.status(400).json({ msg: 'Invalid selection' });

    const bet = new Bet({
      userId: req.user.userId,
      eventId,
      amount,
      selection,
      type: type || 'pre-match',
    });
    await bet.save();

    user.balance -= amount;
    await user.save();

    res.json(bet);
  } catch (err) {
    res.status(500).json({ msg: 'Server error' });
  }
});

// Get user bets
router.get('/', auth, async (req, res) => {
  try {
    const bets = await Bet.find({ userId: req.user.userId }).populate('eventId');
    res.json(bets);
  } catch (err) {
    res.status(500).json({ msg: 'Server error' });
  }
});

// Settle bets for finished events
router.post('/settle', auth, async (req, res) => {
  try {
    const bets = await Bet.find({ userId: req.user.userId, status: 'pending' }).populate('eventId');
    for (let bet of bets) {
      if (bet.eventId.status === 'finished') {
        if (bet.selection === bet.eventId.result) {
          const odds = bet.eventId.participants.find(p => p.name === bet.selection).odds;
          const payout = bet.amount * odds;
          const user = await User.findById(bet.userId);
          user.balance += payout;
          await user.save();
          bet.status = 'won';
        } else {
          bet.status = 'lost';
        }
        await bet.save();
      }
    }
    res.json({ msg: 'Bets settled' });
  } catch (err) {
    res.status(500).json({ msg: 'Server error' });
  }
});

module.exports = router;
```

##### **3. How Winner Prediction Works**

- **Football Matches**:
  - **Odds**: Generated in `generateFootballOdds` (e.g., Team 1: 2.0, Draw: 3.5, Team 2: 3.0).
  - **Probabilities**: `selectWinner` converts odds to probabilities (e.g., 50%, 28.6%, 33.3%).
  - **RNG**: A random number (0–1) selects the outcome based on cumulative probabilities.
  - **Score**: If Team 1 or Team 2 wins, `generateFootballScore` assigns a random score (e.g., 2-1); if Draw, a score like 1-1.
  - **Example**: Lions (2.0) vs. Eagles (3.0), Draw (3.5). RNG selects “Lions” with ~50% chance, score: “2-1”.

- **Dog Races**:
  - **Odds**: Generated in `generateDogRaceOdds` (e.g., Dog 1: 2.0, Dog 2: 3.0, ..., Dog 8: 10.0).
  - **Probabilities**: `selectWinner` assigns higher chances to lower odds (e.g., Dog 1: ~50%, Dog 8: ~10%).
  - **RNG**: Selects one dog as the winner.
  - **Example**: Dog 1 (2.0) has a ~50% chance of winning; RNG selects “Dog 1”.

- **Timing**:
  - Matches/races start every 5 minutes (`date` field).
  - In-play lasts ~3 minutes, after which the RNG determines the winner.
  - Results are stored in `result` and `score` (football only).

- **Bet Settlement**:
  - The `/api/bets/settle` endpoint checks finished events.
  - If the bet’s `selection` matches the event’s `result`, the user wins `amount * odds`.
  - Balance is updated, and bet status changes to “won” or “lost”.
