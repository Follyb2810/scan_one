//= The Odds API, OddsMatrix, or SportsDataIO

To enhance your minimal sports betting app (built with **Express.js**, **MongoDB**, **React Native**) by incorporating **real-time odds**, **payment processing**, and **live streaming or in-game betting** instead of static data and simulated features, you’ll need to integrate third-party APIs and services. These additions significantly increase complexity, cost, and legal considerations compared to the MVP described earlier. Below, I’ll provide a detailed guide on how to source and implement these features, leveraging your existing tech stack, while addressing each requirement practically. I’ll include steps to select providers, integrate their APIs, and update your app’s backend and frontend, along with code artifacts where necessary. I’ll also highlight legal and responsible gambling considerations, as these are critical for real-money betting apps.

---

### **Overview of Requirements and Approach**

1. **Real-Time Odds**:
   - Replace static event data with dynamic odds from a sports betting API.
   - Integrate a provider like **The Odds API**, **OddsMatrix**, or **SportsDataIO** for real-time odds data.
   - Update the backend to fetch and store odds, and the frontend to display them.

2. **Payment Processing**:
   - Replace the simulated wallet with real payment processing for deposits and withdrawals.
   - Integrate a payment gateway like **Stripe** or **PayPal** for secure transactions.
   - Update the backend to handle transactions and the frontend to include payment forms.

3. **Live Streaming or In-Game Betting**:
   - Add **in-game betting** (real-time bet placement during events) as it’s more feasible than live streaming for an MVP.
   - Use the same odds API for in-play odds and update the app to support dynamic bet placement.
   - Note: Live streaming requires complex infrastructure (e.g., Dolby.io, AWS Media Services) and is cost-prohibitive for a minimal app, so I’ll focus on in-game betting but provide guidance if you prefer streaming.

**Constraints**:
- Your tech stack (Express.js, MongoDB, React Native) is suitable but needs scalability enhancements (e.g., caching, WebSockets).
- Real-money betting requires **legal compliance** (e.g., licenses, geolocation, KYC).
- Costs for APIs and services range from $100–$5,000/month, depending on usage.

**Legal Note**: Real-money betting apps must comply with state-specific gambling laws (e.g., 21+ age restrictions, licenses in states like NJ, PA). Consult a legal expert and integrate compliance tools (e.g., geolocation, KYC). For responsible gambling support, contact the National Problem Gambling Helpline at 1-800-522-4700.

##### **Integration Steps**

2. **Update Backend (Express.js)**:
   - Replace the static event data in `routes/events.js` with API calls to The Odds API.
   - Store fetched odds in MongoDB for caching (to reduce API calls and costs).
   - Add a new endpoint to fetch in-play odds for in-game betting.

```javascript
const express = require('express');
const axios = require('axios');
const Event = require('../models/Event');
const router = express.Router();

// Get real-time odds from The Odds API
router.get('/', async (req, res) => {
  try {
    // Fetch odds from The Odds API
    const response = await axios.get('https://api.the-odds-api.com/v4/sports/upcoming/odds', {
      params: {
        apiKey: process.env.ODDS_API_KEY,
        regions: 'us',
        markets: 'h2h', // Moneyline odds
        oddsFormat: 'american',
      },
    });

    // Map API data to Event model
    const events = response.data.map(event => ({
      sport: event.sport_title,
      team1: event.home_team,
      team2: event.away_team,
      odds1: event.bookmakers[0]?.markets[0]?.outcomes.find(o => o.name === event.home_team)?.price || 0,
      odds2: event.bookmakers[0]?.markets[0]?.outcomes.find(o => o.name === event.away_team)?.price || 0,
      date: new Date(event.commence_time),
    }));

    // Save to MongoDB (overwrite existing events)
    await Event.deleteMany({});
    await Event.insertMany(events);

    res.json(events);
  } catch (err) {
    console.error(err);
    res.status(500).json({ msg: 'Error fetching odds' });
  }
});

// Get in-play odds for in-game betting
router.get('/inplay', async (req, res) => {
  try {
    const response = await axios.get('https://api.the-odds-api.com/v4/sports/upcoming/odds', {
      params: {
        apiKey: process.env.ODDS_API_KEY,
        regions: 'us',
        markets: 'h2h',
        oddsFormat: 'american',
      },
    });

    // Filter for in-play events (commence_time < current time)
    const inplayEvents = response.data
      .filter(event => new Date(event.commence_time) < new Date())
      .map(event => ({
        sport: event.sport_title,
        team1: event.home_team,
        team2: event.away_team,
        odds1: event.bookmakers[0]?.markets[0]?.outcomes.find(o => o.name === event.home_team)?.price || 0,
        odds2: event.bookmakers[0]?.markets[0]?.outcomes.find(o => o.name === event.away_team)?.price || 0,
        date: new Date(event.commence_time),
      }));

    res.json(inplayEvents);
  } catch (err) {
    console.error(err);
    res.status(500).json({ msg: 'Error fetching in-play odds' });
  }
});

module.exports = router;
```

To handle real deposits and withdrawals, integrate a payment gateway. Popular options for betting apps include:

  - **Why Choose**: Easy integration, global support, and betting-friendly (with approval).

  - **Features**: Supports e-wallet payments, cards, and Venmo. Trusted by users, with fast deposits/withdrawals.[](https://deadspin.com/betting-payment-methods/)
  - **Pricing**: 2.9% + $0.49 per transaction.[](https://deadspin.com/betting-payment-methods/)
  - **Why Choose**: User familiarity, but stricter approval for gambling.

- **Corefy** (corefy.com):
  - **Features**: Specialized for high-risk industries like betting. Supports cards, crypto, and global methods (e.g., UPI, Pix).[](https://corefy.com/glossary/betting-payment-processing)

  - **Why Choose**: Betting-focused but less beginner-friendly.

**Recommendation**: Use **Stripe** for its ease of integration, reasonable fees, and developer-friendly APIs. Note that betting is considered high-risk, so you’ll need to apply for a merchant account and disclose your business model.

```javascript
const express = require('express');
const Stripe = require('stripe');
const auth = require('../middleware/auth');
const User = require('../models/User');
const Transaction = require('../models/Transaction');
const router = express.Router();

const stripe = new Stripe(process.env.STRIPE_SECRET_KEY);

// Create payment intent for deposit
router.post('/deposit', auth, async (req, res) => {
  const { amount } = req.body; // Amount in USD
  try {
    let user = await User.findById(req.user.userId);
    if (!user.stripeCustomerId) {
      const customer = await stripe.customers.create({
        email: user.username + '@example.com',
      });
      user.stripeCustomerId = customer.id;
      await user.save();
    }

    const paymentIntent = await stripe.paymentIntents.create({
      amount: amount * 100, // Convert to cents
      currency: 'usd',
      customer: user.stripeCustomerId,
      payment_method_types: ['card'],
    });

    res.json({ clientSecret: paymentIntent.client_secret });
  } catch (err) {
    res.status(500).json({ msg: 'Payment error' });
  }
});

// Confirm deposit and update balance
router.post('/deposit/confirm', auth, async (req, res) => {
  const { paymentIntentId, amount } = req.body;
  try {
    const user = await User.findById(req.user.userId);
    const transaction = new Transaction({
      userId: user._id,
      amount,
      type: 'deposit',
      stripePaymentId: paymentIntentId,
    });
    await transaction.save();

    user.balance += amount;
    user.transactions.push(transaction._id);
    await user.save();

    res.json({ msg: 'Deposit successful' });
  } catch (err) {
    res.status(500).json({ msg: 'Error confirming deposit' });
  }
});

module.exports = router;
```

import React, { useState } from 'react';
import { View, Text, TextInput, Button, StyleSheet, Alert } from 'react-native';
import { CardField, useStripe } from '@stripe/stripe-react-native';
import axios from 'axios';
import AsyncStorage from '@react-native-async-storage/async-storage';

export default function DepositScreen({ navigation }) {
  const { confirmPayment } = useStripe();
  const [amount, setAmount] = useState('');

  const handleDeposit = async () => {
    try {
      const token = await AsyncStorage.getItem('token');
      const res = await axios.post(
        'http://localhost:5000/api/payments/deposit',
        { amount: parseFloat(amount) },
        { headers: { Authorization: `Bearer ${token}` } }
      );

      const { clientSecret } = res.data;
      const { error, paymentIntent } = await confirmPayment(clientSecret, {
        paymentMethodType: 'Card',
      });

      if (error) {
        Alert.alert('Payment failed', error.message);
        return;
      }

      await axios.post(
        'http://localhost:5000/api/payments/deposit/confirm',
        { paymentIntentId: paymentIntent.id, amount: parseFloat(amount) },
        { headers: { Authorization: `Bearer ${token}` } }
      );

      Alert.alert('Success', 'Deposit successful');
      navigation.navigate('Profile');
    } catch (err) {
      Alert.alert('Error', err.response?.data?.msg || 'Deposit failed');
    }
  };

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Deposit Funds</Text>
      <TextInput
        style={styles.input}
        placeholder="Amount (USD)"
        value={amount}
        onChangeText={setAmount}
        keyboardType="numeric"
      />
      <CardField
        postalCodeEnabled={false}
        placeholders={{ number: '4242 4242 4242 4242' }}
        cardStyle={{ backgroundColor: '#fff', textColor: '#000' }}
        style={styles.cardField}
      />
      <Button title="Deposit" onPress={handleDeposit} color="#007bff" />
    </View>
  );
}

#### **3. In-Game Betting (Preferred over Live Streaming)**

##### **Why In-Game Betting?**
- **Live Streaming**: Requires high-cost infrastructure (e.g., Dolby.io, AWS Media Services) and rights to stream sports events, costing $10,000+/month. It’s impractical for an MVP due to complexity and licensing.[](https://dolby.io/solutions/sports-betting/)
- **In-Game Betting**: Feasible with The Odds API, which provides in-play odds. It enhances user engagement without the overhead of streaming.[](https://the-odds-api.com/)

##### **Sourcing In-Game Betting Data**
- **The Odds API**: Supports in-play odds for live events (e.g., NFL, NBA). The `/inplay` endpoint in `routes/events.js` filters for live games.[](https://the-odds-api.com/)
- **Alternative Providers**: OddsMatrix, SportsDataIO, or OpticOdds also offer in-play odds but are pricier.[](https://oddsmatrix.com/)[](https://sportsdata.io/live-odds-api)[](https://opticodds.com/sports-betting-api)

const express = require('express');
const auth = require('../middleware/auth');
const Bet = require('../models/Bet');
const User = require('../models/User');
const router = express.Router();

// Place a bet
router.post('/', auth, async (req, res) => {
  const { eventId, amount, selection, type } = req.body; // Add type (pre-match or in-play)
  try {
    const user = await User.findById(req.user.userId);
    if (user.balance < amount) return res.status(400).json({ msg: 'Insufficient balance' });

    const bet = new Bet({
      userId: req.user.userId,
      eventId,
      amount,
      selection,
      type: type || 'pre-match',
    });
    await bet.save();

    user.balance -= amount;
    await user.save();

    res.json(bet);
  } catch (err) {
    res.status(500).json({ msg: 'Server error' });
  }
});

// Get user bets
router.get('/', auth, async (req, res) => {
  try {
    const bets = await Bet.find({ userId: req.user.userId }).populate('eventId');
    res.json(bets);
  } catch (err) {
    res.status(500).json({ msg: 'Server error' });
  }
});

module.exports = router;

import { View, Text, TextInput, Button, StyleSheet } from 'react-native';

import AsyncStorage from '@react-native-async-storage/async-storage';

export default function BetSlipScreen({ route, navigation }) {
  const { event, type = 'pre-match' } = route.params;
  const [amount, setAmount] = useState('');
  const [selection, setSelection] = useState(event.team1);

  const handleBet = async () => {
    try {
      const geoRes = await axios.get('http://localhost:5000/api/geolocation');
      if (!geoRes.data.allowed) return alert('Betting not allowed in your state');

      const token = await AsyncStorage.getItem('token');
      await axios.post(
        'http://localhost:5000/api/bets',
        { eventId: event._id, amount: parseFloat(amount), selection, type },
        { headers: { Authorization: `Bearer ${token}` } }
      );
      alert('Bet placed!');
      navigation.navigate('Profile');
    } catch (err) {
      alert(err.response.data.msg);
    }
  };

  return (
    <View style={styles.container}>
      <Text style={styles.title}>{type === 'in-play' ? 'In-Play Bet' : 'Place Bet'}</Text>
      <Text style={styles.text}>{`${event.team1} vs ${event.team2}`}</Text>
      <TextInput
        style={styles.input}

        value={amount}
        onChangeText={setAmount}
        keyboardType="numeric"
      />
      <Text style={styles.text}>Select Team:</Text>
      <View style={styles.buttonContainer}>
        <Button title={event.team1} onPress={() => setSelection(event.team1)} color="#007bff" />
        <Button title={event.team2} onPress={() => setSelection(event.team2)} color="#007bff" />
      </View>
      <Button title="Confirm Bet" onPress={handleBet} color="#007bff" />
    </View>
